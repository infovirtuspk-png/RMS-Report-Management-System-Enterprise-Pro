Account Recovery

Because RMS operates in an offline, fully private local database environment, password resets must be performed by an Administrator.

Admin Recovery Instructions:
  1. Log in with your primary Administrator account.
  2. Navigate to System → Users & Roles.
  3. Select the target user and click Edit / Change Password.
